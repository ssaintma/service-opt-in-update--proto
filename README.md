# Atelier SMD – impacts sur les équipes de travail

Page d'atelier (prototype) pour recueillir les décisions métier sur les impacts des évolutions du référentiel de services (SMD) sur les équipes de travail (WT).

- `index.html` : la page.
- `shim.js` : enregistrement des réponses dans le navigateur (localStorage). Les réponses restent sur le poste qui les a saisies ; utilisez le récapitulatif en bas de page pour les copier.
